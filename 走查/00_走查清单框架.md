## 轮次产物约定

- 每轮产出两份文件：`RN_报告.md` + `RN_修改清单.md`（N 为轮次，如 `R1_报告.md` / `R1_修改清单.md`）。
- 修改清单必含状态列：**待改 / 已改 / 搁置**。
- 修改后在**同一份清单**复核勾销（改状态、补复核日期），不另开文件。
- 截图命名 `RN-<编号>-<说明>.png`，存 `走查/截图/`。

## B. 规范合规

| 检查项 | 依据 | 检查要点 |
| --- | --- | --- |
| token 绑定 | `设计执行/规范/design.md` + `figma-preferences.md` | 颜色 / 圆角 / 间距 / 阴影 / 文本样式全部绑 semantic token；无裸值；容器无遗留默认白 `#FFFFFF` |
| auto layout | `figma-layer-naming.md` | 容器一律 auto layout；间距用 spacing token；无手动定位残留 |
| 命名 | `figma-layer-naming.md` + `命名规范.md` | 图层 / 组件 / 页面 / section 命名符合规范；无 `Frame 123` 类默认名 |
| UI 文案大小写 | `写作规范.md` | 按组件映射表核对 Sentence case / Title Case；同角色风格一致；发现 ALL CAPS 单独列出交用户定夺 |
| 字重 | `design.md` 文本样式 | 使用 `text/{scale}/{weight}` text style，不手改字重 |
| 图标 | `icons.md` + `figma-preferences.md` | 来源为图标库组件实例；无键盘字符冒充图标；swap 槽位用指定图标库 |
| 基础组件来源 | `components.md` + `figma-preferences.md` | 来自指定组件库；无与库重复的自建基础组件；不引用待归档旧库 |
| 业务组件 | `figma-preferences.md`「业务组件」 | 母版在 Components section；实例未 detach；白名单已登记 |
