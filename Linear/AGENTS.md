# Linear 工单流程

## 读任务

- 一律用 **Linear MCP** 读取工单（标题、描述、评论、附件链接），不退化成网页抓取。
- MCP 掉线 / 鉴权失败时，提示用户重连后再继续，不猜工单内容。
- 工单里的 PRD 链接、Figma 链接同步登记到 `需求文档/00_PRD溯源.md`。

## 处理

- 按根目录 `AGENTS.md` 的任务路由执行；Figma 操作记录写 `设计执行/日志/`。
- 涉及业务规则的疑问进 `需求文档/待确认问题清单.md`，不在工单里替 PM 拍板。

## 处理完自动产出评论草稿

处理完成后在回复里给出评论草稿，**用户手动回评，agent 不代发**。草稿格式：

```
改动范围：<涉及页面 / 节点>
改动内容：
- ...
链接：<Figma 节点链接>（多个逐条列）
cc @<某人>
```

## 记录

- 每处理一单，在 `History.md` 追加一行：日期 / 工单号 / 处理内容 / 状态。
