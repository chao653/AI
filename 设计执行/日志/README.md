# Figma 操作日志 · 格式说明

> Agent 在 Figma 完成任何绘制 / 修改后，把记录写到本目录。走查轮次产物（报告、修改清单、截图）归 `走查/`，不放这里。

## 文件组织

- 按**类型**组织，一个类型一个文件，例如：
  - `需求卡片和标题.md`
  - `节点1_<主题>.md`、`节点2_<主题>.md`…
  - `业务组件_<组件名>.md`
- 新类型出现时新建对应文件；已有类型只在原文件末尾追加。

## 追加规则

- 同一类型的后续操作（包括用户在会话外手工修改的补记）在文件末尾按日期追加小节：

```
## YYYY-MM-DD · 摘要
```

- **只增不覆盖**，不改写历史记录；纠正旧记录时新增一条说明并指向被纠正的小节。

## 每条记录必含

| 字段 | 内容 |
| --- | --- |
| 任务来源 | 用户指令 / Linear 工单号 / 走查修改清单编号 |
| 涉及节点 | node_id + Figma 链接（多个节点逐条列） |
| 操作摘要 | 做了什么、用了哪些组件 / token、有无缺口或降级处理 |
| 结果状态 | 已完成 / 部分完成 / 待用户确认 |

## 截图证据

- 归 `日志/参考截图/`，命名 `YYYY-MM-DD-<说明>.png`。
- 记录里用相对路径引用。

## 记录模板

```
## YYYY-MM-DD · <一句话摘要>

- 任务来源：
- 涉及节点：
  - `<node_id>` — <名称> — <Figma 链接>
- 操作摘要：
  1.
- 结果状态：已完成 / 部分完成 / 待用户确认
- 截图：`参考截图/YYYY-MM-DD-<说明>.png`（如有）
```
